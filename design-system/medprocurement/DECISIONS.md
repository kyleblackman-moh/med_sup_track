# DECISIONS.md: design-system-vendor-applicant

Choices made while running the brief without Kyle. Where the brief and the project rules (CLAUDE.md, design.md) disagree, the project rules win, because CLAUDE.md says they override everything else.

- **D1. MASTER.md does not replace design.md.** The app already has a design system (design.md v0.7.3). MASTER.md is written FROM it and from app.css, for the vendor section, and says design.md wins. Two competing sources would drift. The CLAUDE.md Design section says the same.
- **D2. No ui-ux-pro-max skill.** It is not installed on this machine and installing it would break "no new dependencies" and "ask Kyle before installing". The audit uses design.md, WCAG 2.2 AA and the existing guard tests instead.
- **D3. Scope.** The vendor section is the `requests.*` routes (permission `case.submit`, role `vendor_applicant`): pages/requests/** and components/requests/** (including ad-hoc/). Five components there are also used by staff or admin pages, so they count as shared and are not changed: flash-messages, new-request-button, requests/fields.ts, request-summary, requisition-view. Everything in components/ui, page-header and the layouts is shared too.
- **D4. No scoped copies of shared components.** The brief suggests copies such as `Components/VendorApplicant/Button.jsx`; design.md section 7 says "Do not create duplicate components just to apply the theme". The vendor screens already use the shared Button, SectionPanel, StickyActionBar and ProgressStrip correctly, so issues in shared components (AUDIT 6 and 7) are deferred to a change Kyle approves, not copied.
- **D5. "Tailwind config" is app.css.** Tailwind 4 here is CSS-first (no tailwind.config). New tokens are ADDED to the `@theme` block in resources/css/app.css; nothing existing is renamed or removed.
- **D6. Which values became tokens.** Only the repeated, named design values: helper text 13px (`--text-helper`), field label 15px (`--text-label`), hero title 22px, hero reference 30px, the caption and title letter spacing, the 20px hero tile radius. Values Tailwind 4 already has stay native (`ring-3`, `border-b-3`). Variant brackets (`has-[...]`, `@min-[...]`, `supports-[...]`) and transition property lists are syntax, not design values, and stay.
- **D7. One-off arbitrary values that stay.** `border-[1.5px]` (the selected type card's border, design.md section 7; Tailwind has no 1.5 width step) and `max-h-[90vh]` (a dialog's scroll limit, a layout constraint). Each is noted where it is used.
- **D8. Multi-step indicator.** The request form is one page (design.md section 6 and 11); its ProgressStrip already shows position. No step wizard was added. The older tabbed form for old drafts is left as it is (AUDIT 10, deferred).
- **D9. npm run build.** Run after each phase and page as the brief asks. CLAUDE.md warns it deletes public/hot; on this machine public/hot was still there after every build. If the pages look stale or unstyled, restart `npm run dev`.
- **D10. Tests.** Targeted `php artisan test --filter` runs, one at a time, with DatabaseTransactions (CLAUDE.md); no full suite. A test that pins an old class string is updated to the token; no behaviour expectation changes.
- **D11. Commits.** Staged by explicit path. design.md, adhoc-form-spec.md, reference-v0.7.png and the *-prompt.md files stay untracked. The working tree had no tracked changes, so there was no "WIP" commit.
- **D12. Review and Submit busy state.** Adding a disabled and busy state while the review runs is an interaction state (MASTER.md section 7), not business logic: the same save and the same reload run, it only stops a second press.
- **D13. One test file outside the section changed.** tests/Feature/FormHelperTextTest.php pins the helper class of ad-hoc/fields.tsx; it now expects `text-helper` (same 13px). Reverting it, as the brief's scope check suggests, would leave a failing test, and "fix anything you broke" wins.
- **D14. Requests list unchanged in phase 4.** It already follows MASTER.md (tokens, labelled search, captioned table, empty state, busy state); only the phase 3 token swap touched it.
